# 💱 Conversor de Real para Baht

Programa simples em Python que converte reais (BRL) para baht tailandês (THB).

## O que ele faz
- Pede a taxa de câmbio do dia (1 real = quantos baht)
- Pede o valor em reais
- Mostra o resultado da conversão em baht

## Como rodar
1. Instale o Python 3
2. Baixe o arquivo `conversor.py`
3. No terminal, dentro da pasta do arquivo, digite: `python conversor.py`
